# 🎬 CineVerse

> A movie discovery web application built with HTML, CSS, and JavaScript, powered by the TMDB API.

CineVerse is a movie-focused discovery platform created as one of my first projects while learning **frontend web development**.

The application uses the **TMDB API** to fetch real-time movie information, allowing users to explore trending movies, search for films, view detailed movie information, watch trailers, and save their favorite movies.

---

## ✨ Features

- 🔥 **Trending Movies** — Discover movies currently trending.
- 🔎 **Movie Search** — Search for movies using keywords.
- 🎬 **Movie Details** — View detailed information about individual movies.
- ⭐ **Ratings** — See movie ratings from TMDB.
- 📅 **Release Information** — Check movie release dates.
- 🎭 **Genres** — Explore movie genres.
- 💰 **Box Office Information** — View budget, collection, and estimated profit.
- 🎞️ **Movie Trailers** — Watch available trailers through YouTube.
- ❤️ **Favorites** — Add and remove movies from your personal favorites.
- 💾 **Local Storage** — Favorites are stored locally in the browser.
- 📱 **Responsive UI** — Designed to work across different screen sizes.

---

## 🛠️ Tech Stack

### Frontend

- **HTML5**

### API & Services

- **LocalStorage** — Used to persist favorite movies locally.

## 🚀 How It Works

CineVerse communicates directly with the TMDB API to retrieve movie data.

```text
User
 │
 ▼
CineVerse
HTML + CSS + JavaScript
 │
 ▼
TMDB API
 │
 ▼
Movie Data
 │
 ├── Trending Movies
 ├── Search Results
 ├── Movie Details
 ├── Ratings
 └── Trailers
```

Favorites are stored locally in the user's browser using **LocalStorage**.
